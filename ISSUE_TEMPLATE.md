# Issue Template

This repository uses GitHub issue forms in `.github/ISSUE_TEMPLATE/`.

If forms are unavailable, include:

- Summary.
- Affected path or workflow.
- Whether this is a bug, source update, validator gap, skill request, or documentation issue.
- Redacted minimal example, if relevant.
- Risk if the issue is not fixed.
- Official source URL or `source_id`, if relevant.

Do not include personal data, tax numbers, addresses, invoices, identity documents, or authority correspondence in public issues.
