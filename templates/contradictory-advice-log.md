# Contradictory Advice Log

Use this when a founder has received conflicting advice online or from different people.

| Claim | Source Type | Source URL Or Person | Date Seen | User Action It Would Change | Official Source To Check | Review Owner | Status |
| --- | --- | --- | --- | --- | --- | --- | --- |
|  | Forum / adviser / authority / article / social media |  |  |  |  |  | unverified |

## Handling Rule

Do not resolve conflicting claims by majority vote, confidence, or tone. Route each claim to an official source, user document, qualified professional, or responsible authority. Keep the workflow in preparation status until the claim that would change the user's action is resolved.
